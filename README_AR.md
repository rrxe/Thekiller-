# ODDXS — Telegram Mini App (ألعاب مجانية: Crash · Mines · Dice · Blackjack)

## إعادة التصميم Premium V2

أصبحت الواجهة مبنية من جديد بهيكل موبايل مستوحى من تجربة SLYMintX: Lobby رئيسي مستقل، مكتبة ألعاب، مهام بفلاتر وتقدم، محفظة بسجل موحّد، إحالات، حساب ومشغل موسيقى. أعيد تصميم واجهات Crash وMines وDice وBlackjack برسومات أصلية ولوحات تحكم مختلفة، كما تم تحديث لوحة الإدارة بصرياً.

**تفاصيل التغييرات، الملفات، الفحوص وحدود التحقق:** `REDESIGN_V2_REPORT_AR.md`.

---

مشروع كامل: واجهة React + Tailwind + GSAP، سيرفر Node/Express، قاعدة Supabase (SQL واحد)، لوحة أدمن، سحب إلى **Gram (TON)** أو **Binance ID**.

> ⚠️ **ملاحظات مهمة بصراحة**
> - الألعاب تعمل بنقاط من الإعلانات (بدون إيداع)، لكن إذا كانت النقاط تُسحب كمال حقيقي فقد تُصنَّف قانونياً كلعب/مقامرة في بلدك أو بلد اللاعبين. راجع القوانين وشروط **AdsGram** وتلغرام قبل الإطلاق (ويُفضّل 18+ فقط).
> - المنصّة تحتفظ بحوالي **10%** (RTP 90%) وهذا مكتوب للاعب في صفحة «اللعب العادل». لا توجد خسارة مبرمجة أو «شبه فوز» مزيّف أو صناديق مرتبطة بالخسارة، ولا «معالجة» وهمية للسحب — كل طلب سحب يصلك أنت في لوحة الأدمن وتدفعه يدوياً.
> - لم أستطع تشغيل `npm install` / `vite build` الحقيقيين في بيئة العمل (لا يوجد إنترنت). اختبرت: محرك الألعاب والـ RTP، ملف SQL على PostgreSQL 16، جميع نقاط الـ API ولوحة الأدمن، والواجهة كاملة في Chromium (باستخدام esbuild). شغّل `npm run typecheck` و`npm run build` عندك أول مرة للتأكد.

## 1) قاعدة البيانات (Supabase جديد)
1. أنشئ مشروع Supabase جديد.
2. SQL Editor → الصق كامل محتوى `sql/oddxs_full.sql` → Run. (آمن للتشغيل أكثر من مرة.)
3. Project Settings → API → انسخ **URL** و **service_role key** (للسيرفر فقط، لا تضعه في الواجهة أبداً).
   كل الوصول للجداول يتم عبر دوال `oddxs_*` من السيرفر فقط (RLS مفعّل بدون سياسات عامة).

## 2) المتغيرات
انسخ `.env.example` إلى `.env` واملأ: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `TELEGRAM_BOT_TOKEN`, `BOT_USERNAME`, `WEBAPP_URL`, `ADMIN_SECRET` (+ اختياري `ADMIN_NOTIFY_CHAT_ID`, `ADSGRAM_REWARD_BLOCK`).
> التوكن يجب أن يكون توكن **نفس البوت** الذي يفتح التطبيق (التحقق من initData يعتمد عليه).

## 3) البوت
اتبع `BOT_SETUP_AR.md` (BotFather، رسالة /start بالعربي والإنجليزي، Mini App، روابط الدعوة).

## 4) التشغيل
```bash
npm install
npm run build        # يبني الواجهة (dist) ويولّد server/game-service.gen.js
npm start            # السيرفر على PORT (3000)
```
تطوير: `npm start` في طرفية و`npm run dev` في أخرى (Vite يمرّر /api إلى 3000).
نشر: أي استضافة Node (Railway / Render / VPS / Docker عبر `Dockerfile`) على HTTPS، وضع الرابط في `WEBAPP_URL`. الـ webhook يُسجَّل تلقائياً عند التشغيل.

## 5) لوحة الأدمن — `https://your-domain/admin`
أدخل `ADMIN_SECRET`. فيها: إحصائيات كاملة (مستخدمون، إعلانات، رهانات، RTP الفعلي، ربح المنصة)، **طلبات السحب** (قبول مع مرجع الدفع TX / رفض مع إرجاع النقاط، وإشعار تلقائي للاعب)، المستخدمون (تفاصيل، دفتر حركات، جولات، تعديل رصيد، حظر)، الجولات، سجل التدقيق، وكل **الإعدادات** (مكافأة الإعلان، الكولداون، الحد اليومي، حدود الرهان، سعر النقطة، حدود السحب، إعلانات السحب المطلوبة، تفعيل Gram/Binance، كتلة AdsGram، تفعيل/إيقاف كل لعبة، وضع الصيانة، رسائل الترحيب، جدول الصندوق).

## 6) السحب (مثل SLY)
اللاعب يختار **Gram** (عنوان TON UQ…/EQ…) أو **Binance ID** (6–15 رقم) + المبلغ. شروط من الإعدادات: حد أدنى/أقصى، عدد إعلانات مشاهَدة، فترة انتظار، طلب واحد معلّق. النقاط تُخصم فوراً، وعند الرفض تُرجَع. أنت تدفع يدوياً ثم تضغط «تم الدفع» وتكتب مرجع العملية.

## 7) الإعلانات
أدخل **AdsGram block ID** في لوحة الأدمن → الإعدادات (أو `ADSGRAM_REWARD_BLOCK`). بدون كتلة إعلانات حقيقية **لن** تُمنح نقاط في وضع الإنتاج (حماية من الاستغلال). السيرفر يفرض حد أدنى لزمن المشاهدة + كولداون + سقف يومي.

## 8) الوضع التجريبي (Demo)
فتح الصفحة في متصفح عادي (بدون تلغرام) أو `?demo=1` يشغّل نفس محرك القواعد محلياً على جهازك بشارة «تجريبي» — لا قيمة حقيقية ولا سحب فعلي.

## 9) الأنيميشن والصوت والرسومات
- **كراش**: مشهد فضاء (Canvas): كوكب وقمر ونيازك وقمر صناعي، نجوم بتأثير عمق، صاروخ SVG بلهب ودخان وأثر، عدّ تنازلي 3-2-1، علامات مضاعف (2× 3× 5× 10×…)، انفجار مع موجة صدمة وشظايا، عملات عند السحب، واهتزاز شاشة عند الخسارة. الصاروخ يستمر بالطيران بعد سحبك حتى نقطة الانهيار الحقيقية.
- **شروحات**: زر `?` في كل لعبة (وتظهر تلقائياً أول مرة) — 3 خطوات متحركة (SVG/SMIL) بالعربي والإنجليزي.
- **الصوت**: مؤثرات WebAudio أصلية + مشغل موسيقى بثلاثة مقاطع Ambient أصلية، تشغيل يدوي فقط، السابق/التالي ومستوى الصوت، وكتم منفصل لمؤثرات الألعاب. لا توجد موسيقى تجارية أو أصول خارجية غير مرخصة. لاستعمال أصوات خاصة (مثلاً حزم CC0 من Kenney.nl أو OpenGameArt) ضع mp3 في `public/sfx` (الأسماء في README هناك) وابنِ بـ `VITE_CUSTOM_SFX=1`.
- **الصور**: رسومات مشهد Crash داخل `src/lib/crashArt.ts`، ورسومات بطاقات الألعاب الأربع في `public/images/games/` — أصول SVG أصلية.
> لم أحمّل أي أصول خارجية لأن الشبكة مقفلة في بيئة العمل، لذلك كلها أصلية بدون مشاكل ترخيص.

## 10) العدالة والأمان (مختصر)
- كل الأرصدة والنتائج على السيرفر فقط؛ الواجهة تعرض فقط. كل تغيير رصيد له سطر في دفتر الحركات.
- **Provably fair**: بصمة SHA-256 لبذرة السيرفر تظهر قبل الجولة وتُكشف بعدها (HMAC-SHA256 مع بذرة اللاعب ورقم الجولة).
- كراش: نقطة الانهيار تُحدَّد قبل الإطلاق وتُكشف بعد التسوية؛ تسعير السحب بزمن السيرفر.
- تحقق initData من تلغرام (HMAC) + حدّ طلبات + حماية من تكرار التسوية.

## لوحة الأدمن (`/admin`) — المهام والإحالات

افتح `https://your-domain.com/admin` من أي متصفح وأدخل `ADMIN_SECRET`.

- **✅ المهام**: أضف/عدّل/أوقف/احذف مهام. النوع «قناة» يتحقق البوت تلقائياً من الاشتراك عبر `getChatMember` (يجب أن يكون البوت **مشرفاً** في القناة، وضع معرّفها `@channel`). النوع «رابط» لا يمكن التحقق منه من تلغرام، فيُشترط انتظار عدد ثوانٍ بعد فتحه فقط.
  لكل مهمة: المكافأة بالنقاط، أقصى عدد منجزين، الترتيب، التفعيل.
- **⚙️ الإعدادات ← الإعلانات والمكافآت**:
  - `سعر الإحالة` (`referral_reward_pts`): مثلاً 10 أو 50 نقطة.
  - `عدد المهام المطلوبة` (`referral_required_tasks`): 5 أو 10 أو أي رقم (0 = بلا شرط).
  - `عدد الإعلانات المطلوبة` (`referral_ads_required`) — اختياري، يُجمع مع شرط المهام.
  تُدفع المكافأة للداعي **مرة واحدة** فقط عندما يحقق المدعو كل الشروط.
- **👥 المستخدمون**: بحث، حظر/فك حظر، إعطاء/خصم نقاط (يُسجَّل في السجل المالي والتدقيق).
- **💸 السحوبات**: قبول/رفض مع مرجع الدفع. **📣 بث**، **🛡️ مشرفون بصلاحيات**، **🧾 سجل تدقيق**.

> إن كان لديك قاعدة بيانات قديمة: شغّل `sql/oddxs_full.sql` مرة أخرى (آمن للتكرار) لإضافة جداول المهام.

## الاشتراك الإجباري وقناة إثباتات الدفع

- **🔒 الاشتراك الإجباري** (تبويب في /admin): أضف قنوات (الاسم، `@channel`، الرابط). لا يستطيع المستخدم اللعب أو الإعلانات أو المهام أو السحب قبل الاشتراك في كلها، وتظهر له شاشة «اشترك للمتابعة» مع زر تحقق. **يجب أن يكون البوت مشرفاً في كل قناة.** التشغيل/الإيقاف الكلي من ⚙️ الإعدادات.
- **قناة السحب**: ضع معرّفها في ⚙️ الإعدادات ← عام ← «قناة إثباتات الدفع» (أو `PAYMENT_CHANNEL_ID` في env). عند قبول أي سحب يُنشر في القناة: المستخدم، المبلغ بـ USDT، الطريقة (Binance ID / GRAM Wallet)، العنوان، ثم `@ODDXS_BOT`. البوت يجب أن يكون مشرفاً في القناة.
