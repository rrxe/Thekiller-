# Stormy ⚡ — بوت + Mini App جاهز للنشر على Dokploy (Docker)

تطبيق مستقل بهوية وميكانيكا أصلية:
- **بوت تيليجرام حقيقي** (Node.js + grammY) يرسل زر "فتح التطبيق" عبر `/start`.
- **خادم ويب** (Express) يقدّم واجهة الـ Mini App (`index.html` / `style.css` / `app.js`).
- إعلانات **AdsGram Rewarded** مدمجة في مكان واحد فقط، اختيارية وغير مرتبطة بأي وظيفة أساسية.

---

## 1) ما الذي يجعل هذا التطبيق مختلفًا عن مجرد قالب؟

| الميزة | الوصف |
|---|---|
| **تحدي رد الفعل (البرق)** | لعبة مهارة حقيقية: انتظار ظهور البرق ثم الضغط بأسرع وقت، 5 محاولات يوميًا، المكافأة تعتمد على سرعة رد فعل المستخدم الفعلية — وليست عجلة حظ عشوائية |
| **سؤال اليوم** | كويز معلومات عامة يتغيّر يوميًا (بنك أسئلة دوّار)، إجابة صحيحة = مكافأة فورية |
| **تسجيل دخول يومي** | سلسلة 7 أيام بمكافآت متصاعدة |
| **مهمة الانضمام للقناة** | مكافأة لمرة واحدة بعد التحقق من الضغط |
| **إعلان مكافأة اختياري** | مكان واحد فقط (بطاقة "شاهد إعلان" بالصفحة الرئيسية)، محدود بـ 3 مشاهدات/يوم، لا يؤثر على أي وظيفة أساسية |

> **مهم:** قبل أي محاولة نشر أو مراجعة، تأكد فعليًا أن التطبيق يعمل بحساب تجريبي حقيقي (سجّل دخولًا، جرّب التحدي، جاوب على السؤال) — التطبيق الجاهز فقط بدون استخدام فعلي لن يكفي لاجتياز أي مراجعة جادة، بما فيها Adsgram.

---

## 2) الإعداد قبل النشر

### أ) أنشئ بوت في BotFather
1. `/newbot` في [@BotFather](https://t.me/BotFather) واحصل على `BOT_TOKEN`.

### ب) اضبط رابط القناة (لمهمة الانضمام)
افتح `public/index.html` وضع رابط قناتك الحقيقية في:
```html
window.CONFIG = { ADSGRAM_BLOCK_ID: "...", CHANNEL_URL: "https://t.me/اسم_قناتك" };
```

### ج) احصل على blockId من AdsGram
1. أنشئ حسابًا على [partner.adsgram.ai](https://partner.adsgram.ai).
2. أنشئ Block من نوع **Rewarded**.
3. ضع القيمة في نفس السطر أعلاه بدل `ADSGRAM_BLOCK_ID`.
4. **مهم لاجتياز الموديريشن:** بعد النشر، تأكد أن الإعلان يظهر فعليًا عند الضغط على زر
   "شاهد إعلان" في الصفحة الرئيسية (هذا هو مكان عرض الإعلان الوحيد في التطبيق).

---

## 3) النشر على Dokploy

1. ادفع هذا المجلد إلى مستودع Git (GitHub/GitLab) أو ارفعه مباشرة إذا كان Dokploy يدعم رفع Zip.
2. في Dokploy: **Create Application** → اختر **Dockerfile** كطريقة البناء، واربط المستودع.
3. اضبط متغيرات البيئة في تبويب **Environment** (راجع `.env.example`):
   ```
   BOT_TOKEN=توكن_البوت
   WEBAPP_URL=https://your-domain.com
   CHANNEL_URL=https://t.me/اسم_قناتك
   PORT=3000
   ```
4. اضبط **Domain** في Dokploy على نفس القيمة الموجودة في `WEBAPP_URL`.
5. اضغط **Deploy**. بعد نجاح النشر:
   - افتح `https://your-domain.com` للتأكد أن الواجهة تعمل.
   - أرسل `/start` للبوت في تيليجرام وتأكد أن زر "⚡ فتح Stormy" يفتح التطبيق فعليًا.

> ملاحظة: البوت يعمل بنظام Long Polling، لذا لا حاجة لإعداد Webhook أو فتح منفذ إضافي له — فقط منفذ الويب (`PORT`) يحتاج أن يكون مكشوفًا لـ Dokploy.

## 4) هيكل المشروع

```
.
├── Dockerfile
├── .dockerignore
├── .env.example
├── package.json
├── server.js          # خادم Express + بوت grammY
└── public/
    ├── index.html     # واجهة الـ Mini App + سكربت AdsGram
    ├── style.css
    └── app.js          # منطق التطبيق (localStorage) + التحدي + الكويز + AdsGram
```

## 5) التشغيل محليًا (اختياري، قبل النشر)

```bash
cp .env.example .env   # عدّل القيم
npm install
npm start
```

ثم افتح `http://localhost:3000` في المتصفح للتأكد من عمل الواجهة (زر الإعلان لن يعمل فعليًا إلا داخل تيليجرام وبعد ضبط blockId صحيح ونشر الرابط عبر HTTPS).

---

## 6) نصيحة قبل التقديم للمراجعة مرة أخرى

- استخدم التطبيق فعليًا لعدة أيام (تسجيل دخول، تحدي، كويز) قبل التقديم، حتى يكون هناك نشاط حقيقي وسجل استخدام.
- إذا كنت تخطط لصرف مكافآت حقيقية للمستخدمين لاحقًا (USDT أو غيره)، جهّز إثبات دفعات موثوق (رسالة مثبّتة أو قناة مخصصة) لأن Adsgram يشترط ذلك بشكل منفصل عن مسألة "القالب".
- غيّر أي أثر متبقٍ لاسم "SLY" أو أي نسخة سابقة (روابط، صور، نصوص) إن وُجد في أي مكان آخر من مشروعك خارج هذه الملفات.
